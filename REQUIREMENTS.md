# Requirements

This document lists all software versions and tools required to build and run the application.

---

## Backend (Java)

- **Java**: JDK 21 (Eclipse Temurin 21 JDK)
- **Maven**: 3.9.12
- **MongoDB Java Driver Sync**: 4.11.1

---

## Frontend (React)

- **Node.js**: 22.22.0
- **npm**: 11.8.0
- **Vite**: 7.2.4
- **React**: 19.2.0
- **React DOM**: 19.2.0

---

## Tools

- **Docker**: For backend deployment
- **MongoDB Atlas**: Cloud database for conversion history
